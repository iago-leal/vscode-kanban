1. O defeito

No diálogo Edit a card, os campos Description e Details não recebem cursor nem aceitam texto quando estão vazios. Com conteúdo, funcionam — foi o que o relator observou ao ver que, "depois que algo é escrito, aí fica editável".

2. Causa raiz (confirmada por medição)

O wrapper que o design system desenha em volta do <textarea> é display: flex. O editor aberto por CodeMirror.fromTextArea é inserido dentro desse wrapper e vira flex item com flex: 0 1 auto: a largura passa a vir do conteúdo, não do container. Conteúdo vazio significa largura zero — o editor encolhe até a calha dos números.

A folha do projeto declara altura para esse editor (dialogs.css:87-89) e nunca declarou largura. O comentário que acompanha a regra discute apenas altura: a largura passou despercebida porque, com texto, o editor se estica sozinho.

O diff de CHG-003, como será

+    width: 100%;
+    min-width: 0;
     height: calc(var(--vsckb-editor-rows, 5) * 1.5em + 16px);

min-width: 0 não é decoração: um flex item tem min-width: auto por padrão, o que o impede de encolher abaixo do conteúdo. Sem ele, uma linha muito longa passaria a esticar o diálogo em vez de rolar dentro do editor — que é exatamente a regressão que o comentário de altura da folha diz ter combatido uma vez.

Adicionar um browser à suíte só por este bug seria desproporcional; se virar necessidade recorrente, é decisão própria, não carona nesta correção.

6. Riscos e escopo negativo

Risco: baixa

  • Uma declaração de geometria numa folha de estilo; sem efeito em domínio, dados ou ponte.
  • Reversível por remoção. Nenhum byte do arquivo do quadro muda.
  • Nenhuma âncora de style-anchors.md é renomeada: contrato externo intacto.
  • Risco residual: a folha do usuário (.vscode/vscode-kanban.css) é carregada por último e pode sobrescrever a largura. É o mesmo risco que já vale para a altura.

Fica de fora desta correção

  • O limite de 255 caracteres que só o diálogo de edição impõe à descrição — defeito conhecido e preservado de propósito (EditCardDialog.tsx, legacy-impact.md). Outra correção, outro bug.
  • Qualquer refatoração do MarkdownField ou do adaptador. A correção é cirúrgica.
  • O cartão do quadro de ~/dev/experimento: nada será escrito nele.
